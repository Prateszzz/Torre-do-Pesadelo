Migração do Backend

Torre do Pesadelo — copia todos os dados do projeto antigo para o projeto novo.
Importante: durante a migração, deixe as regras de segurança do projeto NOVO em modo de teste (aberto, permitindo leitura e escrita). Feche as regras depois que a migração terminar. Se as regras do destino bloquearem a escrita, a migração vai falhar.

1Configuração do projeto NOVO (destino)

2Login

Use o mesmo email e senha que você usa no portal (projeto antigo). O script conecta no projeto antigo para ler os dados e no projeto novo para escrever.

3Migrar

Copia todas as coleções do projeto antigo para o novo, preservando os IDs. Pode rodar de novo sem duplicar (sobrescreve).

Não apague o projeto antigo até confirmar que tudo funcionou no projeto novo. A migração copia os dados, mas não remove nada do antigo.
